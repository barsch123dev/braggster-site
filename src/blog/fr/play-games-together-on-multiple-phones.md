# Comment jouer à des jeux de société ensemble sur plusieurs téléphones

Un jeu de société sur un seul téléphone marche très bien, jusqu'au moment où le téléphone doit traverser
la table à chaque tour. Le mode Jouer ensemble de Braggster donne à chaque joueur son propre téléphone
et garde une seule partie en direct sur tous, via le Wi-Fi que tu utilises déjà. Ce guide explique
comment le mettre en place, quels jeux le proposent, et quoi vérifier quand une table n'apparaît pas.

## Trois façons de jouer entre amis

**Un seul téléphone, qu'on se passe.** Chaque plateau jouable de Braggster fonctionne en alternance sur
un seul appareil. Il ne faut rien d'autre que le téléphone, et c'est toujours le moyen le plus rapide de
lancer une partie de Chess ou de Dominoes.

**Jouer ensemble, un téléphone chacun.** Un téléphone ouvre une table et les autres la rejoignent sur le
même Wi-Fi. Tout le monde voit le même plateau et les mêmes scores, mis à jour en direct, et joue sa
propre place depuis son propre téléphone.

**Pas par internet.** Jouer ensemble est fait pour des gens dans la même pièce. Les téléphones se parlent
sur ton réseau local, pas par internet, donc il n'y a aucun compte à créer et aucun serveur entre les
deux. Un ami dans une autre maison ne peut pas rejoindre.

## Pas à pas : ouvrir une table et la rejoindre

1. **L'hôte ouvre un jeu** qui prend en charge Jouer ensemble et appuie sur **Jouer ensemble**, puis sur
   **Ouvrir une table**. Le téléphone de l'hôte affiche un code QR et devient la table.
2. **Tous les autres rejoignent** sur leur propre téléphone, sur le même Wi-Fi : ouvre Braggster, appuie
   sur **Scanner un code** et pointe l'appareil photo vers l'écran de l'hôte.
3. **Ou choisis-la dans la liste.** La table apparaît aussi sous **Tables sur ce Wi-Fi**, un joueur peut
   donc la toucher là plutôt que de scanner.
4. **L'hôte accepte.** Un code scanné fait entrer le joueur directement. Celui qui a choisi la table dans
   la liste attend que l'hôte appuie sur **Accepter**.
5. **Lance la partie.** Une fois tout le monde installé, l'hôte démarre, et chaque joueur joue sa place
   sur son propre téléphone.

## À quels jeux jouer ensemble

- **[Yahtzee](/games/yahtzee/)**, jusqu'à six joueurs. L'hôte peut activer les dés numériques pour la
  table : celui dont c'est le tour lance sur son propre téléphone, et tous les autres voient les dés
  tomber sur le leur. Chaque joueur remplit sa propre colonne. Voir le
  [guide de comptage du Yahtzee](/blog/how-to-score-yahtzee/).
- **[Chess](/games/chess/)**, avec chaque coup légal vérifié sur les deux plateaux.
- **[Checkers](/games/checkers/)** et **[International draughts](/games/dammen/)**, y compris les longues
  séries de prises.
- **[Backgammon](/games/backgammon/)**, avec les victoires simples, les gammons et les backgammons comptés
  comme d'habitude. Voir le [guide de comptage du Backgammon](/blog/how-to-score-backgammon/).
- **[Othello](/games/reversi/)**, où chaque retournement apparaît sur les deux écrans.

Sur les plateaux, le dernier coup est marqué sur les deux téléphones, pour que tu voies ce que ton
adversaire vient de faire dès que tu regardes ton écran. La vue d'ensemble des plateaux se trouve dans le

## iPhone et Android à la même table

Une table peut mélanger librement iPhone et téléphones Android. Jouer ensemble passe par le Wi-Fi et non
par le Bluetooth, et c'est exactement ce qui permet aux deux types de téléphones de se retrouver.

Rejoindre est gratuit. Seul l'hôte a besoin du jeu : un joueur qui rejoint n'a pas besoin de le posséder
ni d'avoir encore des parties gratuites, donc le téléphone d'une seule personne ne bloque jamais la table.

## Est-ce que ça compte dans tes statistiques ?

Oui. Une partie en Jouer ensemble est enregistrée sur chaque téléphone à table et compte dans les
statistiques de chaque joueur, taux de victoire et séries compris, exactement comme une partie jouée sur
un seul téléphone. Les parties d'entraînement contre l'ordinateur font exception : elles ne comptent
jamais, sur aucun appareil.

## Quand la table n'apparaît pas

Presque tous les problèmes viennent de téléphones qui ne se voient pas sur le réseau.

- **Autorise le réseau local sur iPhone.** La première fois que tu ouvres ou rejoins une table, iOS
  demande si Braggster peut utiliser le réseau local, « pour héberger et rejoindre une feuille de score
  partagée avec d'autres joueurs sur le même WiFi ». Appuie sur Autoriser. Si tu as refusé, réactive
  Réseau local pour Braggster dans les Réglages de l'iPhone.
- **Scanne le code plutôt que d'utiliser la liste.** La liste des tables repose sur des téléphones qui se
  trouvent automatiquement, et certains réseaux bloquent cela en silence. Le code QR contient l'adresse de
  l'hôte, donc le scanner connecte directement. Un joueur peut aussi saisir l'adresse affichée sous le
  code.
- **Utilise ton Wi-Fi de maison.** Les réseaux invités, et beaucoup de réseaux d'hôtel, de bureau ou
  d'école, isolent volontairement les appareils les uns des autres. Dans ce cas rien ne peut se
  connecter, même avec le code, et la solution est d'utiliser un Wi-Fi de maison ordinaire.
- **Vérifie que tout le monde est sur le même réseau.** Un téléphone repassé en données mobiles, ou
  connecté à un autre Wi-Fi dans la même maison, ne trouvera pas la table.

## Questions fréquentes

**Peut-on jouer aux échecs à deux sur deux téléphones ?**
Oui. Avec Jouer ensemble, un téléphone ouvre une table et l'autre la rejoint sur le même Wi-Fi. Les deux
joueurs voient le plateau en direct et chacun joue depuis son propre téléphone.

**Faut-il une connexion internet ?**
Non. Les téléphones ont seulement besoin d'être sur le même Wi-Fi. Rien ne passe par internet et il n'y a
aucun compte à créer.

**iPhone et Android peuvent-ils jouer ensemble ?**
Oui. Une table peut mélanger librement iPhone et téléphones Android.

**Combien de joueurs peuvent rejoindre une table ?**
Le Yahtzee accueille jusqu'à six joueurs, un téléphone chacun. Chess, Checkers, International draughts,
Backgammon et Othello sont des jeux à deux joueurs, donc deux téléphones.

**Tout le monde doit-il acheter le jeu ?**
Non. Seul l'hôte a besoin du jeu. Rejoindre une table est gratuit.

**Pourquoi mon ami ne voit-il pas la table ?**
Vérifie que les deux téléphones sont sur le même Wi-Fi et, sur iPhone, que Braggster peut utiliser le
réseau local. Si la table n'apparaît toujours pas, scanne le code de l'hôte. Sur un réseau invité ou
d'hôtel, les téléphones peuvent être totalement isolés, alors passe sur un Wi-Fi de maison.
